# Release validation — 2026-10-27

## Confirmed

- Clean Python virtual environment with isolated site-packages, using the existing Windows 64-bit CPython 3.13.9 interpreter/stdlib. This was not an independently installed OS or Python distribution.
- Runtime dependencies installed from PyPI as binary wheels only; fully pinned requirements including all 11 runtime packages. `pip check` found no broken requirements. No packages in the user's Anaconda environment were upgraded.
- The five sanitized manifests validate their unchanged CSV hashes, shell geometry and normalized low-q values against the documented numbers.
- The no-browser command completed target extraction and leave-one-ratio-out training for Linear, RBF and Matérn 3/2 GPs plus mean and linear baselines. Five regression models each retain five held-out points, with five folds.
- Saved JSON RBF model reconstructed and returned predictions for two new ratio queries through the separate condition CLI.
- Three bounded release tests pass: manifest/target parity; real loopback HTTP start, Host/Origin/Fetch Metadata/API/session/report/path checks and example loader; confirmed run deletion in disposable fixtures preserving its input source.
- Browser observation confirmed the header example loader, populated local CSV source and parameters, 5/5 low-q data check, consistent numbered navigation and the session-protected embedded report with observed points, held-out points and regression curves. The GP run used for this visual check was generated by the same Workbench CLI workflow, without retraining through the browser a second time.
- The targeted release scan returns no matching credential, account, private-path or Drive-identifier findings in distributed files. Manifest checksums and ZIP contents are checked during final packaging.
- OSV queried for every pinned runtime dependency on the review date; no known advisory IDs were returned for these versions. This is a time-bound database result, not a complete security guarantee.

## Not validated

macOS/Linux runtime behavior; another Python version; a new machine with different filesystem policies; live Google OAuth/Drive access; organization data-sharing permission; actual experimental SANS/SAXS agreement; complete raw/early-task regression suites in this release round; scientific generalization across seeds or stages. Optional features are preserved from the current code and clearly labelled in FEATURES.md.

The browser screenshot and test outputs remain in a local validation workspace and are not shipped with personal paths in the public package. No original research run or raw data was deleted or uploaded.

## Repeat the necessary checks

```sh
python -m unittest tests.test_release
python run_example.py --out runtime --target low_q_shell_mean --kernels linear rbf matern_32
python scripts/check_release.py
```

The first command uses disposable fixtures and local HTTP only. The second writes a new execution under `runtime/`. The scanner prints categories and filenames, never matched secret values. To validate an edited source tree rather than the immutable release file list, use `python scripts/check_release.py --source-tree`.

If environment policy rejects a loopback bind, report that failure separately; do not disable endpoint protection/firewall to obtain a pass. If a Python installer cannot write its temporary directory, use a writable per-process temporary directory; this does not require changing the machine's global protections.
