結構因子定義、邊界與單位換算

Scc(k,t) = |cB ρA(k,t) − cA ρB(k,t)|² / N；ρX = ΣX exp(i k·r)，cX = NX/N。占比取自實際粒子數，不把配方鏈數比例當粒子占比。

k = 2π(nx/Lx, ny/Ly, nz/Lz)。計算上限內所有非零倒格向量；±k 只計一次，分箱平均強度。q 座標是分箱內實際 |k| 的平均。使用三方向週期邊界及固定正交盒；此曲線為組成結構因子，實驗權重另在下方設定。

時間 = step × 時間量 + 位移。更改長度單位時，q 上限、分箱寬度與目標頻帶須使用相應的倒數長度單位，並重新計算／檢查。

實驗對照準備：SANS／SAXS 獨立散射設定

用 AA、BB、AB 部分相關項與散射權重，產生 SANS／SAXS 對照曲線。

J = bA² PAA + bB² PBB + 2 bA bB PAB；S_weighted = J / (cA bA² + cB bB²)。b 是含粗粒化映射及必要溶劑對比的每粒子有效實數振幅，不是直接填 SLD。J 尚未轉換為絕對實驗強度。

q 相依權重在各分箱平均 q 以線性內插求值，不外插；需檢查分箱寬度收斂。這裡使用已換算時間，端點須對應保存的 frames。實驗解析度、背景與絕對強度標定尚未處理。

時間窗決定平均區間；分段數用於比較窗口內的變化。

峰值定義與篩查方法
  • 選取搜尋範圍內最高的網格點；若落在邊界、平台或曲線近乎平坦，標示待確認。不平滑、不插值。
  • 相對 prominence = 峰的突出程度 /（曲線最大值 − 最小值），用來衡量峰相對於整段曲線的突出程度。
  • 其他局部峰的 prominence 達到主峰的指定比例時，標示競爭峰。
  • 全窗口與各分段峰位的最大值減最小值，需不超過容許值；各分段也必須能辨識主峰。
  • 通過只代表符合宣告篩查規則，不證明平衡、物理峰存在或跨 seed 穩定性。q 網格無法辨識小於其解析度的移動。
  • 時間分段僅用於診斷，每個 seed 仍只產生一筆訓練資料。請在比較模型前固定提取規則。

q 頻帶決定納入目標的空間尺度；時間窗決定平均區間。

頻帶沿用研究的 q 單位；分段數用於比較時間窗內 M 的變化。

CSV 請選 sqt.csv，並保留相鄰的 manifest.json。

M 的定義與適用條件

M = Σ nᵦ [S̄ᵦ − 1] / Σ nᵦ，其中 S̄ᵦ 是時間平均的 Scc/(cA cB)，nᵦ 是分箱方向數；q=0 排除。M 的物理下限是 −1，表示相對於獨立隨機粒子參考的頻帶起伏超額，不是混合百分比。

頻帶需包含完整分箱；方向數與正規化由 manifest 核對。0–0.2 為目前資料的起始頻帶，換單位或研究尺度後須重新設定。

每個 seed 產生一筆標籤；分段差距供診斷，不是獨立樣本或平衡證明。提取規則應在模型比較前固定。

q 頻帶決定納入目標的空間尺度；時間窗決定平均區間。

L=128、q 單位為 simulation_length^-1 時，0–0.11 包含五個非零 shell。CSV 請保留相鄰的 manifest.json。

低 q 平均的定義與適用條件

低 q 平均 = (1/K) Σₖ S̄cc,norm(qₖ)：先平均時間，再對頻帶內 K 個完整 shell 等權平均；排除 q=0，不減 1。

Scc,norm(q) = |c₂ρ₁(q) − c₁ρ₂(q)|² / (N c₁c₂)，ρₐ(q)=Σⱼ∈ₐ exp(i q·rⱼ)，cₐ=Nₐ/N 取自實際粒子數，並非配方欄的 A:B。Scc,norm 是正規化濃度結構因子，與未正規化的 Scc 區別。

每個 shell 的 q 長度相同，方向平均含正負向量；各 shell 等權，與 M 按方向數加權並減 1 不同。要求完整 shell、同一 q 網格及單位；已混合不同 shell 的分箱不能用插值還原。CSV 模式須保留旁邊的 manifest.json。

數值非負，1 僅代表獨立隨機粒子的參考，不是聚合物混合度門檻，也不是越高越好。低 q 可含鏈內相關；不是 q→0 極限或實驗散射強度。分段差距不等於信賴區間；每個 seed 仍僅一筆標籤。

固定設定與推論限制
  • Linear 的 sigma_0 固定為 1；Matérn 的 ν 固定為選定的 3/2 或 5/2。其他 kernel 的 length_scale 初值為 1、範圍 0.01–100；Rational Quadratic 的 alpha 亦為 1、範圍 0.01–100。數值在標準化 input 空間定義，與訊號幅度和噪音一起只在每輪訓練資料上最佳化。
  • 固定隨機種子 20261020，最佳化額外重啟 2 次。完整設定保存到 config.json。
  • 一個 seed 無法直接估計每個配方的 seed 間變異。預測區間以已擬合超參數為條件，沒有積分超參數不確定性。
  • 三個中間比例屬於 ratio 插值，兩端屬於 ratio 外插。結果為探索性比較，沒有自動贏家或巢狀選模。
  • 評分門檻仍未設定；本頁的峰值篩查門檻與模型勝負門檻不同。

結果解讀
